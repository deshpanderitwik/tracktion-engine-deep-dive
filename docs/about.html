About this site

What it is

A teaching artifact about how a production digital audio workstation engine is actually put together. The subject is Tracktion Engine, the engine behind the Waveform DAW, open-sourced and maintained by Tracktion. The audience is a developer who wants to build the next generation of DAWs and needs to understand what components one contains, how they interconnect, and how they collaborate to let people produce music.

What it isn't

It isn't a reference. It isn't auto-generated. It isn't exhaustive. If you need the full API surface, read the Doxygen or the headers themselves. This site picks a dozen specific cross-sections through the codebase and explains them well, because twelve deep diagrams teach more than a hundred shallow ones.

How it was built

The repository was cloned with --recurse-submodules and every diagram was built by reading the actual source. Doxygen, DeepWiki, and prior knowledge of other DAWs were supporting context only — never a substitute for opening the header. When I couldn't verify a relationship from the source, it didn't go on the diagram; it became a flag.

The visual grammar is deliberately constrained. Three edge kinds, two accent colors, one flag color. Swimlanes vary by diagram topic but look and behave the same on every page. Node labels are file paths or class names, never prose. Commentary is in the margin, not inside the box.

Version

Everything on this site reflects the repository at commit 2877b621 (version 3.2.0, 2026-02-18). If the codebase has moved on since, some file paths may have drifted; the diagrams should still read true at the subsystem level.

Corrections

If a diagram or flag is wrong, say so — being corrected is the whole point of writing this down. A diagram that paints an incomplete picture honestly is more valuable than one that paints a complete picture wrong.
