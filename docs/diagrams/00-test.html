Pipeline check: every feature, dummy data

This page exercises every feature of the shared diagram component against fabricated content. If you can read the tooltip, click a node and see teal/amber highlighting, click a flag in the sidebar and see pinned nodes, and toggle the flow overlay to animate a path — the pipeline works end to end. Delete this page before shipping.

What you should see

Two swimlanes. Five nodes. One solid edge (ownership), one dashed edge (runtime message), one dotted edge (data flow). Two flags pinned to nodes. One flow overlay that you can toggle from the sidebar to animate the dotted edge with a moving amber dash pattern.

If any of those are missing, the scaffold is broken and downstream diagrams will inherit the bug. Fix here first, then proceed to diagram 1.
